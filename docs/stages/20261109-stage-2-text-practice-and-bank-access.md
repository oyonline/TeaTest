## 1．根本问题与硬约束

其他科目的用户需要自己的题库和文字作答入口。只隐藏菜单无法隔离数据，现有 A–E 判分和 10 字符答案字段也不能承载文字答案。共用现有系统、后台和账号；保留原题库、已存答案、成绩及重置密码功能；本卡批准前不施工。

## 2．做 / 不做

- **分配题库**：答题人管理增加“可访问题库”多选、回显和保存；未分配则无题库。取消授权后，下一次请求即禁止该题库列表、题目、续答、结果及相关统计，原记录保留，重新授权后可访问。用户身份取服务端认证，不能靠入口参数放行。
- **存量兼容**：一次性给上线前已有用户分配当时已有题库；以后新用户、新题库均不自动授权，重启不能重复补授。历史未分类考试不再走全题库续答：保留原记录和成绩，提示按具体题库新开；不自动删记录或改成绩。
- **独立入口**：`/practice` 登录、`/practice/banks` 选库，使用中性文案；登录、刷新、结果返回、退出及过期返回保留该入口。新增固定“通用题库”分类；旧入口展示竞赛/考级，新入口展示通用题库，均只显示已授权的库。列表、统计及进行中提示按“授权∩入口分类”过滤；入口参数只能缩小范围。账号与后台共用，入口不增加权限。
- **文字练习**：新增 `fill_blank`、`short_answer`；两个入口共用同一答题与结果组件，均支持单选、多选、判断、填空、简答，题型不受题库分类限制。文字答案支持中文、大小写、标点、换行，最多 4000 个 Unicode 字符。填空按整段文字作答，仅去首尾空白、统一换行后匹配；不做同义词或语义判分。简答只供对照，不增自评分数录入。提交成功后锁定，刷新可恢复；最后一题也能查看参考答案再进入结果。提交前 API 不返回标准/参考答案，文字按纯文本显示。
- **导入与结果**：沿用 CSV 列结构，新题型可无选项；支持带引号的多行文字，保留答案大小写。新题沿用 CSV 导入，不新增单题编辑器。未知题型或任一非法行整批拒绝，原库不变；同题干、不同题号保留。简答显示“未自动评分”，只计已答数，不计对错、自动得分或正确率分母；全简答时不显示自动分数/正确率。原客观题规则保留。
- **不做**：第二套部署/域名、多租户组织、图片音视频、富文本、AI/人工阅卷、复杂多空解析、同义答案库、原试卷 100 分权重重构、无关重构。

## 3．验收（开工前固定）

| 场景 | 必须观察到的结果 |
|---|---|
| 用户甲仅分配 A，乙仅分配 B | 两入口按分类和授权交集展示；改题库/考试/题目 ID 无法跨权读取、作答、看结果或统计，拒绝请求写入 0 行 |
| 保存/撤销授权 | 普通用户不能分配；非法 ID 整批拒绝、原分配不变；撤销后旧 Token 下次请求即拒绝，重新分配可恢复；新用户无授权为空态 |
| 迁移、重启与旧记录 | 存量分配只初始化一次，重启不恢复已撤销权限、不放行后来新库；原题目/答案/成绩无丢失；未分类考试不再跨库续答 |
| 文字往返与保密 | 连接/答案列为 utf8mb4；含 emoji 的 4000 字混合文本可导入、作答、刷新；4001 字及纯空白拒绝、不截断；未答不泄露答案，含最后一题提交后可查看完整参考答案 |
| 判分 | 2 填空（1 对 1 错）＋2 简答全部提交后：已答 4、对 1、错 1、未自动评分 2、正确率 50%、自动得分 1/2；全简答完成但不显示 0 分/0% |
| 导入与回归 | 多行文字、重复题干保留；坏行整批不落库；两个入口各完成一份五题型混合卷（覆盖原客观题）；统计/进行中提示仅当前入口；重置密码可用；`/practice` 刷新及返回不串入口 |

验证预算：批准施工后做一轮受影响的 Go 单测＋真实本地 MySQL 集成、一次前端构建、两入口桌面/手机宽度回归；不跑无关全量。失败保留原证据，报告缺口，不自行增加验证轮次。
